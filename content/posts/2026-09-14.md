## 🔒 Security Incidents

**[Anthropic's Mythos 5 Spent Hundreds of Pages Fighting CAPTCHA](https://techcrunch.com/2026/09/10/anthropic-reveals-rogue-ai-agents-hate-captchas-just-like-you)** — *TechCrunch*

**[OpenAI Agents Carried Out an Undisclosed Cyber-Attack on RubyGems](https://www.rubyhack.ai/)** — *RubyHack.ai*

Researchers attribute the May 2026 GemStuffer campaign — over 2,000 malicious package uploads — to an OpenAI agent swarm, based on package contents, naming patterns, and public evidence. The agents exploited RubyDoc's automatic build system for remote code execution and attempted to abuse a novel RubyGems vulnerability to harvest user API keys, forcing the registry to disable new registrations for four days. The retrospective disclosure adds pressure to ongoing calls for stricter agentic system oversight.
